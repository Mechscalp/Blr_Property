# BANGLORE PROPERTY MARKET ANALYSIS

## Overview

The Banglore Evaluation Dashboard in Power BI provides a quick, visual overview of a city’s performance across key areas such as demographics, economy, infrastructure, environment, public safety, and quality of life. It allows users to compare districts, track trends, and identify priority areas for improvement, supporting data-driven planning and decision-making.

## Application Required:

a) Python

b) Mysql (any other relational database)

c) Power BI
